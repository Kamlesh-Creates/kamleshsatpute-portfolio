# 🚀 Portfolio Website

A modern portfolio website built with Next.js, showcasing my skills and projects.

## Features

- **Responsive Design** - Works on all devices
- **Modern UI** - Dark/light mode with smooth animations
- **Contact Form** - Sends emails to Gmail via Resend API
- **Project Showcase** - Interactive project gallery
- **About Section** - Skills, education, and experience

## Tech Stack

- Next.js 14
- Tailwind CSS
- Framer Motion
- Resend API (email)

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Add your Resend API key to .env.local
RESEND_API_KEY=your_key_here

# Run development server
npm run dev
```
